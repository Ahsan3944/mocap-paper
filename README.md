# MoCap Paper

A Paper 1.21.11 plugin that faithfully ports the features and command-based workflow of the Minecraft Motion Capture (MoCap) mod to Paper, with no GUI, no extra features, and no omitted functionality.

## Target

- Platform: Paper
- Minecraft: 1.21.11
- Interface: Commands only
- GUI: None
- Goal: Feature and behavior parity with the upstream MoCap mod

## Status

Project foundation. Implementation follows the upstream MoCap command and behavior model, adapted to the Paper API.
